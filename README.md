## Descripción del proyecto

Este proyecto consiste en un programa realizado en Python que calcula el costo total de una compra.

El programa solicita al usuario el nombre del producto, precio, cantidad y porcentaje de descuento. Después calcula el subtotal, descuento, IVA y total a pagar.

## Tecnologías utilizadas

- Python
- GitHub

## Funcionamiento

El programa utiliza:

- `input()` para solicitar información al usuario.
- Variables de tipo `str`, `int` y `float`.
- Operaciones aritméticas para realizar los cálculos.
- `print()` y f-strings para mostrar los resultados.
